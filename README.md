# Uber Data Analytics Dashboard | Power BI

## Project Overview
This project uses Microsoft Power BI to explore and visualize Uber trip data through an interactive dashboard. The objective is to present data in a visual format to support analysis of trip-related patterns and trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objectives
- Explore Uber trip data.
- Analyze trip-related trends and patterns.
- Present data using interactive visualizations.
- Build a dashboard to make data easier to understand.

## Dashboard
The dashboard was developed using Power BI to present Uber data through visual reports.

## Project File
- `uberproject.pbix` – Power BI dashboard file.

## How to View the Project
1. Download the `uberproject.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report and dashboard pages.
